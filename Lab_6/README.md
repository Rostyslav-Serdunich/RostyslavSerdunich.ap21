##  Огляд проекту
Цей проект є реалізацією Лабораторної роботи №6, присвяченої вивченню фундаментальних принципів ООП: інкапсуляції, спадкування, поліморфізму та абстракції. Програма розроблена у багатофайловому форматі для забезпечення модульності та зручності читання коду.

##  Структура та логіка завдань

### 1. Клас Person 
Реалізовано клас, що описує людину. Демонструє використання конструкторів (default та з параметрами) для ініціалізації полів `fullName` та `age`. Методи `move()` та `talk()` визначають базову поведінку.

### 2. Клас Phone (Перевантаження та Varargs)
Клас для роботи з характеристиками телефонів.
- **Перевантаження:** Метод `receiveCall` реалізований у двох варіантах (тільки ім'я або ім'я + номер).
- **Varargs:** Метод `sendMessage` приймає довільну кількість номерів телефону для масової розсилки.
- **Валідація:** Реалізовано перевірку номера телефону за допомогою регулярних виразів.

### 3. Ієрархія Shape (Спадкування)
Побудовано ієрархічну модель геометричних фігур:
- `Shape` (базовий клас для об'єму).
- `SolidOfRevolution` (додає поняття радіуса).
- `Cylinder`, `Ball`, `Pyramid` (конкретні реалізації з розрахунком об'єму).

### 4. Абстрактний клас Car (Абстракція)
Демонстрація використання абстрактних методів. Клас `Car` визначає загальну структуру автомобіля, а похідні класи `Sedan` та `Truck` реалізують специфічну логіку гальмування через метод `brake()`.

### 5. Комплексні числа (Математична логіка та Перевизначення)
Реалізація роботи з комплексними числами в тригонометричній формі.
- **TrigComplexNumber:** реалізує піднесення до степеня за формулою Муавра.
- **ExtendedTrigComplexNumber:** розширює базовий клас додатковими полями та перевизначає метод `print()` для детального виведення даних.

## Обробка винятків (Exception Handling)
Для забезпечення стабільності роботи програми впроваджено систему перевірки введення:
- Блоки `try-catch` перехоплюють помилки при введенні некоректних типів даних (наприклад, літери замість чисел).
- Цикли `while` змушують користувача повторити введення до отримання коректного значення.
- Очищення буфера `Scanner` після кожного зчитування числа.

##  Запуск програми
1. Відкрийте проект у вашому IDE (наприклад, IntelliJ IDEA).
2. Скомпілюйте всі файли `.java`.
3. Запустіть файл `Main.java`.
4. Виконуйте інструкції в терміналі для послідовного проходження всіх завдань.
