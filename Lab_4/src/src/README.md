# Лабораторна робота №4: Робота з масивами в Java

## Огляд проекту
Цей проект є виконанням лабораторної роботи №4 з дисципліни програмування. Програма демонструє різні методи роботи з одновимірними масивами: створення, ініціалізацію, перебір за допомогою різних циклів, обчислення агрегованих значень та модифікацію елементів за певними умовами.

## Структура програми
Програма реалізована за модульним принципом. Кожне завдання винесене в окремий клас, що має власний метод `main`. Це дозволяє запускати кожну частину роботи незалежно або всі разом через головний файл.

### Склад файлів:
1.  **`Main.java`** — Головний клас (точка входу), який послідовно викликає виконання всіх завдань.
2.  **`Task1.java`** — Робота з великими масивами (парні та непарні числа).
3.  **`Task2.java`** — Робота з фіксованим масивом, демонстрація циклів `for`, `while` та виведення за індексами.
4.  **`Task3.java`** — Обчислення суми дійсних чисел (`double`).
5.  **`Task4.java`** — Логічна модифікація знаків елементів масиву.

## Детальний опис завдань

### Завдання 1: Заповнення масивів закономірностями
Клас `Task1` створює два порожніх масиви розміром по 50 елементів. Використовується оператор `new` для виділення пам'яті в "купі" (heap), а посилання на ці області зберігаються в змінних `evenNumbers` та `oddNumbers`.
* **Перший масив**: заповнюється 50 парними числами (від 2 до 100).
* **Другий масив**: заповнюється 50 непарними числами (від 1 до 99).

### Завдання 2: Алгоритми перебору та виведення
Клас `Task2` використовує заданий масив з 10 чисел: `[2, 17, 13, 6, 22, 31, 45, 66, 100, -18]`.
В межах цього завдання реалізовано:
* Виведення всіх елементів за допомогою циклу `while` та `for`.
* Виведення чисел лише з **непарними індексами** (1, 3, 5...) за допомогою кроку `+= 2`.
* Виведення чисел лише з **парними індексами** (0, 2, 4...).
* Реверсивне виведення масиву (від останнього індексу `length-1` до `0`).

### Завдання 3: Агрегація даних
Клас `Task3` демонструє роботу з дійсними елементами (`double`). Програма проходить по всьому масиву та накопичує суму всіх значень у змінній `sum`. Це демонструє здатність Java працювати з різними типами даних у масивах.

### Завдання 4: Модифікація вмісту
Клас `Task4` фокусується на зміні даних всередині масиву. Програма знаходить всі непарні числа (елементи, значення яких не ділиться на 2 без остачі) і змінює їхній математичний знак на протилежний.
