# Лабораторна робота №8

## Тема: Потоки вводу/виводу. Програмне керування файловою системою в Java

---

## 1. Мета та завдання роботи
**Мета:** Глибоке вивчення архітектури пакета `java.io`, набуття практичних навичок роботи з символьними потоками даних, автоматизація процесів створення, запису та зчитування текстових файлів.

**Основні завдання:**
* Розробка багатофайлової архітектури додатка для розділення логіки інтерфейсу та бізнес-логіки.
* Реалізація механізму динамічного створення файлів з перевіркою їхнього стану в системі.
* Генерація числової послідовності за заданим математичним алгоритмом.
* Забезпечення надійного зчитування та виведення даних у термінал.

---

## 2. Технологічний стек та інструментарій
* **Мова програмування:** Java (JDK 17+).
* **Пакет:** `java.io` (основні класи: `File`, `FileWriter`, `FileReader`).
* **Середовище:** IntelliJ IDEA / Terminal.
* **Механізми:** Try-with-resources (автоматичне закриття потоків), генерація псевдовипадкових чисел (`java.util.Random`).

---

## 3. Архітектура та структура проекту
Проект реалізовано за принципом розділення відповідальності:

### А. Клас `Main` (Точка входу)
Відповідає за конфігурацію програми. Тут визначаються константи:
* `fileName` — шлях до цільового файлу.
* `b1`, `b2` — межі числового діапазону.
  Викликає методи обробки, забезпечуючи лінійний хід виконання.

### Б. Клас `FileTask` (Логічне ядро)
Містить інкапсульовану логіку роботи з дисковим простором:
1.  **`writeRandomNumbers(String, int, int)`**:
    * Ініціалізує об'єкт `File`.
    * Виконує превентивну перевірку `exists()`.
    * Створює потік `FileWriter`.
    * Виконує циклічний запис за формулою: `rand.nextInt(b2 - b1 + 1) + b1`.
2.  **`readFromFile(String)`**:
    * Відкриває потік зчитування `FileReader`.
    * Здійснює посимвольне сканування файлу.
    * Виконує типізацію та виведення інформації.

## 4. Глибокий аналіз використаних методів

### Система потоків
У даній роботі акцент зроблено на **символьних потоках**. На відміну від байтових потоків (`FileInputStream`), символьні потоки оперують типом `char` (16-біт), що дозволяє коректно обробляти текстову інформацію, враховуючи кодування.

### Обробка виняткових ситуацій (Exception Handling)
Робота з файловою системою є потенційно нестабільною операцією. Програма обробляє `IOException`, що може виникнути у випадках:
* Відсутності прав доступу на запис у директорію.
* Апаратних збоїв диска.
* Спроби читання файлу, який було видалено іншим процесом під час роботи програми.

### Автоматичне закриття ресурсів
Використання `try-with-resources` запобігає витокам пам'яті та блокуванню файлів операційною системою. Потоки закриваються миттєво після виходу з блоку `try`, навіть якщо сталася помилка.

## 5. Результати та верифікація
При запуску програми спостерігається наступний цикл:
1.  **Консольне підтвердження**: Програма повідомляє про створення файлу або виявлення вже існуючого.
2.  **Фізичний запис**: На диску з'являється файл (наприклад, `my_numbers.txt`) із записаними числами через пробіл.
3.  **Термінальний вивід**: Вміст файлу дублюється в консоль у реальному часі.
