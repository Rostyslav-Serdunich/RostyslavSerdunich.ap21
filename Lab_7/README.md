# Лабораторна робота №7: Робота з колекціями в Java (ArrayList та HashMap)

Даний проєкт демонструє роботу з динамічними структурами даних у Java. Програма розділена на два основні модулі, що виконують завдання згідно з методичними вказівками.

##  Структура проєкту

Проєкт реалізовано у багатофайловому форматі для дотримання принципів ООП:
- `Driver.java` — модель водія.
- `Car.java` — модель автомобіля (властивості, конструктор, методи модифікації).
- `Helper.java` — допоміжний клас для випадкового вибору авто.
- `TaxiService.java` — головний клас першого завдання (ArrayList).
- `PhoneBook.java` — головний клас другого завдання (HashMap + інтерактивне меню).

---

##  Функціонал програми

### Завдання 1: Автопарк (ArrayList)
Програма автоматично створює список з 10 автомобілів та виконує наступні дії:
1. **Ремонт:** Половині автопарку збільшується потужність двигуна на 10% та призначаються нові водії.
2. **Тюнінг:** Кожній другій машині збільшується потужність на 10% та ціна на 5%.
3. **Курси водіїв:** Якщо водій старше 25 років, але має стаж менше 5 років, його досвід автоматично збільшується (імітація підвищення кваліфікації).
4. **Виклик таксі:** Випадковим чином обирається автомобіль, і в консоль виводиться повідомлення про виїзд та прибуття водія.

### Завдання 2: Телефонна книга (HashMap)
Інтерактивна програма, що працює через термінал:
1. **Попереднє наповнення:** При старті додається 10 сталих контактів (прізвище та номер).
2. **Візуалізація:** Перед кожним вибором дії програма виводить актуальний список усіх абонентів.
3. **Методи Map:** Реалізовано функції додавання (`put`), пошуку (`get`), видалення (`remove`), перевірки наявності ключа/значення (`containsKey`/`containsValue`) та визначення розміру книги (`size`).
4. **Безпека:** Використовується блок `try-catch` для обробки винятків та перевірка регулярними виразами, що забороняє введення літер замість цифр у номері телефону.

---

##  Технології та поняття 

- **Інкапсуляція:** Всі поля класів `private`. Доступ до них обмежений.
- **Конструктори:** Використовуються для ініціалізації об'єктів при створенні.
- **Валідація:** Перевірка вводу через `matches("\\d+")` (тільки цифри).
- **Колекції:** - `ArrayList` — для роботи з впорядкованим списком об'єктів.
    - `HashMap` — для швидкого пошуку за унікальним ключем (прізвищем).

##  Як запустити
1. Скомпілюйте файли: `javac *.java`
2. Для запуску першого завдання: `java TaxiService`
3. Для запуску другого завдання: `java PhoneBook`
