# Лабораторна робота №3: Складання програм циклічної структури

##  Мета роботи
Отримати навички побудови алгоритмів циклічної структури за допомогою операторів `while` та `for`.

##  Опис виконаних завдань

Проект містить рішення для 18-го варіанта (відповідає №6 у загальному списку):

1.  **Виведення фрази 50 разів** (`Task1.java`):
    * Реалізовано за допомогою циклу `for`.
    * Реалізовано за допомогою циклу `while`.
2.  **Імітація часу (Години:Хвилини)** (`Task2_3.java`):
    * Виведення від 0 h 0 min до 2 h 59 min за допомогою циклу `for`.
    * Аналогічне виведення за допомогою циклу `while`.
3.  **Імітація часу (Години:Хвилини:Секунди)** (`Task4.java`):
    * Виведення від 0 h 0 min 0 sec до 2 h 59 min 59 sec.
4.  **Табулювання функції** (`Task5.java`):
    * Протабульовано функцію на проміжку `[-2; 2]` з кроком `0.2` (Варіант 6)].
    * Додано введення меж діапазону з клавіатури.
    * Реалізовано обробку винятків `try-catch` для захисту від некоректного введення.

## 🛠 Використані інструменти
* **Мова:** Java.
* **Цикли:** `while`, `for`, `for-each`.
* **Обробка помилок:** `try-catch` блоки для `InputMismatchException`.
