# Лабораторна робота №5: Побудова методів та багатофайлова архітектура в Java

Дана програма розроблена для демонстрації принципів створення методів, передачі параметрів, обробки винятків та організації багатофайлової структури (Clean Architecture) у мові Java.

---

##  Функціонал програми

Програма є інтерактивною консольною аплікацією, яка виконує наступні завдання:
1. **Геометрія (Варіант 4):** Обчислення площі ромба за двома введеними діагоналями.
2. **Робота з числами:** Знаходження та повернення найменшого значення серед трьох цілих чисел.
3. **Робота з масивами:** - Виведення елементів масиву в консоль.
    - Пошук та повернення найбільшого числа у масиві.

Всі дані для обчислень вводяться користувачем з клавіатури під час виконання програми.

---

##  Структура проекту

Проект розділено на 4 взаємопов'язані файли за принципом єдиної відповідальності (Single Responsibility Principle):

* **`Main.java`** — Головний клас програми. Відповідає за спілкування з користувачем (через консоль), зчитування введених даних, виклик методів з інших класів та виведення фінальних результатів на екран.
* **`Geometry.java`** — Клас-утиліта, що містить математичну логіку. Метод `getRhombusArea(double d1, double d2)` обчислює площу ромба.
* **`Number.java`** — Клас-утиліта. Метод `findMinimum(int a, int b, int c)` порівнює три числа і повертає найменше з них.
* **`Array.java`** — Клас-утиліта для колекцій даних. Метод `printArray(int[] array)` виводить масив, а `findMaximum(int[] array)` шукає найбільший елемент.
